# 🗄️ DB-Studio

**DB-Studio** è una piattaforma web educativa per l'apprendimento dei **database relazionali** in **10 giorni**.

## 🎯 Cosa fa DB-Studio?

DB-Studio offre un percorso formativo completo e strutturato per imparare i fondamenti e le tecniche avanzate dei database relazionali. Il corso segue l'approccio **"Learn by Doing"**: prima pratichi su un database reale, poi approfondisci la teoria.

### ✨ Caratteristiche principali

- 📚 **10 lezioni strutturate** - Un percorso progressivo dal livello base all'avanzato
- 🎮 **Esercizi interattivi** - Quiz e verifiche per consolidare l'apprendimento
- 💻 **50+ esercizi pratici** - Per mettere in pratica ogni concetto
- 📊 **100+ query SQL** - Esempi concreti e commentati
- 🏆 **Progetto finale** - Realizza un database completo (e-commerce o gestionale)

## 📖 Programma del Corso

| Giorno | Argomento | Descrizione | Durata |
|--------|-----------|-------------|--------|
| 1 | **Modello Relazionale** | Tabelle, tuple, attributi, chiavi primarie e vincoli | 3-4 ore |
| 2 | **Algebra Relazionale** | Selezione, proiezione, join e operatori relazionali | 4-5 ore |
| 3 | **SQL Fondamentale** | SELECT, WHERE, ORDER BY, GROUP BY, HAVING | 5-6 ore |
| 4 | **SQL Avanzato** | Subquery, JOIN complessi, funzioni aggregate | 5-6 ore |
| 5 | **Normalizzazione** | 1NF, 2NF, 3NF, BCNF - progettazione ottimale | 4-5 ore |
| 6 | **Modello E-R** | Entità, relazioni, cardinalità, progettazione concettuale | 4-5 ore |
| 7 | **Indicizzazione** | B-Tree, Hash, ottimizzazione performance | 3-4 ore |
| 8 | **Transazioni** | ACID, concorrenza, locking, isolamento | 4-5 ore |
| 9 | **Tecnologie Avanzate** | Trigger, stored procedure, viste materializzate | 5-6 ore |
| 10 | **Progetto Finale** | Database completo: e-commerce o gestionale | 8-10 ore |

## 🚀 Come Iniziare

1. Clona il repository
2. Avvia un server PHP locale (es. `php -S localhost:8000`)
3. Apri il browser su `http://localhost:8000`
4. Inizia dal **Giorno 1** e segui il percorso!
