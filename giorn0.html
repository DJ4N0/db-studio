📘 Giorno 1 - Modello Relazionale

Chiavi nel Modello Relazionale

Le chiavi sono fondamentali per identificare univocamente le tuple in una relazione:

Superchiave

Insieme di attributi che identifica univocamente le tuple

Esempio: (codice_fiscale, nome) per una relazione Persona
Chiave Primaria

Chiave candidata scelta per identificare le tuple

Esempio: codice_fiscale per una relazione Persona
Struttura di una Relazione

Una relazione è composta da:

  • Attributi: Colonne che definiscono le proprietà
  • Tuple: Righe che contengono i dati
  • Dominio: Insieme di valori che un attributo può assumere
CREATE TABLE Studente ( matricola INT PRIMARY KEY, nome VARCHAR(50) NOT NULL, cognome VARCHAR(50) NOT NULL, data_nascita DATE );
